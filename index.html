    THE PROBLEM

    AI agents can act.
    Your security controls need to keep up.

    AI agents can call APIs, access databases, send messages, modify records, and execute workflows.

    The risk isn't what your agent says. It's what your agent is allowed to do.

    HOW IT WORKS

    Every tool call gets a decision.

    AgentGate puts a policy enforcement layer between agent decisions and real-world actions, and evaluates each action at runtime before it reaches the systems your agent can access.

    AI AgentTool call
    AgentGatePolicy evaluation · Risk assessment · Runtime enforcement
    DecisionALLOW · ASK · BLOCK
    ALLOW

    Safe actions continue.

    ASK

    Sensitive actions require human approval.

    BLOCK

    Unauthorized or dangerous actions are stopped.

    TWO LAYERS

    One control boundary. Two ways to use it.

    AgentGate Runtime

    CONTROL AT RUNTIME

    Control, test, and investigate agent actions.

    Give your agents room to act without giving them unlimited authority.

    01 · CONTROL

    Define and enforce policies for every agent action.

    Wrap a tool once. From then on, every call is checked against your policy before the real handler runs.

    protect-first-tool.mjs
    const gate = createAgentGate({
  agent: 'SupportAgent',
  mode: 'enforce',
  policies: { approvalAmount: 5000 }
});

// wrap the tool before the agent sees it
const refund = gate.protect(
  refundHandler,
  { tool: 'refund', action: 'refund' }
);

    USE CASES

    Built for agents that touch real systems.

    Support agents

    An agent should not delete a customer on its own.

    delete_customer → ASK for human approval.

    Finance agents

    Refunds need limits, not trust.

    refund $8,000 → BLOCK above the limit.

    Data agents

    Bulk exports should never run by accident.

    export_all → BLOCK on the block list.

    Read-only work

    Safe actions keep flowing without friction.

    read_customer → ALLOW and continue.

    DEVELOPER EXPERIENCE

    Add control without rebuilding your agent.

    Connect your agent, define a policy, run a tool call, and inspect the decision.

    $ npm install agentgate-runtime-control
    agent.mjs
    import { createAgentGate } from 'agentgate-runtime-control';

const gate = createAgentGate({
  agent: 'SupportAgent',
  mode: 'enforce',
  policies: {
    approvalAmount: 5000,
    blockActions: ['export_all']
  }
});

const refund = gate.protect(
  async ({ amount, customerId }) => ({ refunded: amount, customerId }),
  { tool: 'refund', action: 'refund' }
);
    before
    const refund = refundHandler;
    after
    const refund = gate.protect(refundHandler, {
  tool: 'refund', action: 'refund'
});
